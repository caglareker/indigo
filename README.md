# caglareker.com

Personal website of Caglar Eker, built with [Jekyll](https://jekyllrb.com/) using the [Indigo](https://github.com/sergiokopplin/indigo) theme.

## Local Development

```sh
bundle install
bundle exec jekyll serve
```

Open [http://localhost:4000](http://localhost:4000)

Or run with Docker:

```sh
docker-compose up
```
